# Gravity Runner Support

Thanks for playing Gravity Runner.

For help, feedback, purchase questions, or bug reports, contact:

admin@dmtools.fun

Please include:

- Device model
- Android version
- Galaxy Store version if relevant
- What happened
- Steps to reproduce the issue
- Screenshot if available

## Common Topics

### Remove Ads

If you purchased Remove Ads and ads still appear, try using the Restore button on the start screen.

### Rewarded Ads

Rewarded ads are optional and may be used to receive extra retries when available.

### Progress Reset

The Reset Progress button clears local game progress on the current device.
